# Mangiapalline

Un gioco del labirinto con fantasmi, in un solo file HTML.

## Come si gioca

Mangia tutte le palline senza farti prendere. Le palline grandi spaventano i fantasmi: per qualche secondo puoi mangiarli tu.\n\nFrecce o W A S D per muoverti, P o Spazio per la pausa, M per l'audio. Sul telefono si scorre il dito sul labirinto o si usano i tasti a schermo.

## Provarlo

È un solo file, `index.html`: scaricalo e aprilo nel browser. Non serve installare niente e non si connette a nessun server (usa solo i caratteri di Google Fonts).
